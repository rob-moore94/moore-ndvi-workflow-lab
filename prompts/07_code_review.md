# Part 7: Review code written by an agent (20 min, no AI)

`review/agent_written_ndvi.py` was written by an AI coding agent in one turn,
from a one-line prompt and without an AGENTS.md file. Read it carefully. Do
not run it, and do not use AI for this part.

Find at least six problems. For each one, write in `REVIEW.md`:

- the line number(s)
- what is wrong
- what would happen if the script were run (wrong numbers, a crash, lost
  files, an error that is hidden, and so on)
- how you would fix it

Use lectures 22 to 24 and your own `AGENTS.md` as a checklist. Some problems
are scientific, some are about the workflow design, and some are about error
handling. Look also for problems that combine: one mistake can be hidden by
another.
